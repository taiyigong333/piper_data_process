# OpenPI 绝对动作训练变换核查

## 结论

支持。当前 `openpi` 子模块中的 `LeRobotLiberoDataConfig` 提供 `extra_delta_transform`。当其设为 `true` 时，训练输入对动作执行相对化；数据集文件本身仍可保存绝对动作。

## 代码依据

`openpi/src/openpi/training/config.py` 的 `LeRobotLiberoDataConfig.create` 在 `extra_delta_transform=True` 时使用：

```python
delta_action_mask = _transforms.make_bool_mask(6, -1)
data_transforms = data_transforms.push(
    inputs=[_transforms.DeltaActions(delta_action_mask)],
    outputs=[_transforms.AbsoluteActions(delta_action_mask)],
)
```

`openpi/src/openpi/transforms.py` 中的 `DeltaActions` 对掩码选中的维度执行：

$$a_{rel} = a_{abs} - s_{current}$$

`AbsoluteActions` 在策略输出阶段执行逆变换：

$$a_{abs} = a_{rel} + s_{current}$$

`make_bool_mask(6, -1)` 表示前六维为 `true`，第七维为 `false`。因此，对本项目的 `[J1, J2, J3, J4, J5, J6, gripper]`：

- 数据集：绝对关节目标和绝对夹爪开度；
- 训练目标：六维相对关节动作和绝对夹爪开度；
- 推理输出：六维绝对关节目标和绝对夹爪开度。

OpenPI 预置的 `pi0_libero` 与 `pi0_fast_libero` 配置已使用 `extra_delta_transform=True`，证明该路径是现有受支持用法。

## 适用边界

该掩码是关节空间的逐元素相减，不包含欧拉角回绕或四元数/SE(3) 组合。因而当前结论适用于默认的六关节 `joint_positions` 配置。若改用 TCP 姿态，尤其跨越欧拉角 $\pm\pi$ 或使用四元数时，应实现专门的 SE(3) 相对变换，不应直接沿用这一设置。
